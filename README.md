# Brisa

Pedestrian-scale sunlight and ventilation diagnostics for informal settlements — a morphometric
pipeline computing street-level solar access and flow-regime indicators for five settlements in
Rio de Janeiro.

## Status

Code accompanying a manuscript currently under review. On publication of the manuscript, this
repository will carry the full analysis pipeline and figure code (archived with a Zenodo software
DOI), alongside two data records: an open de-georeferenced table set (CC BY 4.0) and a
request-gated georeferenced record. Until then, code and data are available to editors and
reviewers through the journal.

## Planned contents

On release this repository will contain: the morphometric indicator pipeline, solar aggregation
and regime classification, sensitivity analyses, all figure-generation code, and a pinned
Python environment with per-figure reproduction commands.
